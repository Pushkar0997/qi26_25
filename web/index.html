What was found

The results are largely negative and are reported as such. A tuned demonstration would have been easier to produce and worth less.

Quantum features ≈ classical

92.2% vs 91.9%

At matched dimensionality the quanvolutional layer ties a classical convolution — and both lose to raw pixels (93.6%). Training the filter does not close the gap.

Grover's √N does not survive

N1.39

Measured CX cost per oracle call grows faster than linearly in text length, because loading classical text into the circuit dominates. The query advantage is real; the end-to-end speedup is not.

The bottleneck is classical

6.5%

Clean-document character error rate. Fixing a train/serve skew cut it 6.6×, which was worth more than any quantum component — and it was found because a better feature set produced worse output.

How it works

Why no quantum simulator runs here

Both quantum stages reduce to small dense linear algebra, so the browser reproduces them exactly rather than approximating them.

Quanvolutional layer. The filter is a fixed circuit, so it is one 16×16 unitary. The angle encoding produces a product state, so a patch's statevector is a Kronecker product of four single-qubit states and the layer is a matrix–vector product — precisely what Aer computes.

Grover search. The comparator oracle was measured in Python to have zero uncomputation leakage: the window register returns exactly to |0⟩, leaving the position register unentangled. That measurement is what licenses simulating the position register alone here. The reduced dynamics are exact, and the leakage check is the evidence.

The full circuit for a 16-character field is 14 qubits with ~3,300 CX gates. The page reports those real costs even though it does not execute the full circuit.

Honest limitations

  • The model was trained on synthetic documents (rendered, then degraded under controlled parameters). Exact ground truth is what makes character error rate computable at all, but real scans differ.
  • Its character set is A–Z 0–9 - : in a sans/serif face at one size. Photos, unusual fonts, coloured backgrounds and handwriting will degrade badly — that is a property of the training data, not a bug.
  • The Grover stage searches the hex-representable ID field only: a full 38-symbol alphabet needs 6 qubits per character, past what is simulable.
  • Segmentation is projection-profile based and fails on low-DPI scans where glyphs merge (recovering ~36% of characters on the noisy tier).
